# Android 도구와 교사 환경 기록

학생은 Unity Hub에서 해당 Editor와 함께 설치한 Android SDK·NDK·OpenJDK를 사용합니다. 학습문서의 External Tools 설정을 따르며, 교사 컴퓨터의 전역 SDK 경로를 그대로 가져오지 않습니다.

재구성 전 교사 환경에서는 Platform Tools 37.0.1이 설치되어 있어도 Command-line Tools 23의 목록 출력 형식을 Unity가 읽지 못해 0.0으로 표시하는 문제가 있었습니다. 당시에는 설치된 호환 도구를 빌드 동안만 선택한 뒤 복원했습니다. 이는 과거 환경 진단 기록이며 새 프로젝트의 필수 설정이 아닙니다.

이전 내부 API 기반 빌드 보조 코드는 재구성 전 Git bundle과 보관 태그에 남아 있습니다. 새 과정에는 해당 도구를 실행하는 절차를 넣지 않습니다. 이번 재구성 작업은 컴퓨터의 전역 SDK·NDK·JDK 설정을 변경하지 않았습니다.

새 소스의 Android APK 빌드·기기 실행을 수행했는지는 VALIDATION.md에서 확인합니다. 과거 APK 빌드 성공을 새 소스의 실기기 실행 결과로 대신하지 않습니다.
