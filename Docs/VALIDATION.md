# 재구성 후 검증 범위

2026-10-20에 변경된 학습 순서로 일차별 완료 상태를 다시 구성합니다. Evidence/Rebuild의 JSON에는 해당 소스에서 수행한 씬·컴파일·실행 검사 결과를 기록합니다.

기존 Windows·Android·Web 빌드와 브라우저·성능·복원 검증은 재구성 전 Git bundle에 보관했습니다. 디스크의 기존 Builds 출력은 새 브랜치 소스를 빌드한 결과라는 의미가 아닙니다. 재구성 후 Player 빌드·실기기·브라우저 검증은 실제로 수행한 항목만 별도로 기록합니다.

1일차에 Assets의 프로젝트 C# 파일이 없는지, 각 UI가 해당 일차에 처음 등장하는지, 누락 스크립트·Inspector 참조·버튼 이벤트·코인 열 개가 맞는지 검사합니다. 이 정적 씬 검사는 실제 입력·물리·OS 중단·HTTPS 요청의 실행 검증과 구분합니다.

학생의 NCS 성취 여부는 교사 프로젝트의 검사 결과로 대체하지 않습니다. 학생이 자신의 설계·실행·오류 복구·측정·인수인계 자료를 제출해야 합니다.
