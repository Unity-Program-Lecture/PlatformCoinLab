# 프로파일 기록

14일차에는 같은 Player 조건에서 기존 RefreshUi와 표시 값 캐시를 추가한 결과를 비교합니다. 메뉴·진행·결과의 실제 UI를 대상으로 CPU Timeline·GC Alloc을 확인하고 원본 Profiler 자료와 3회 측정값을 보관합니다.

Editor에서 메서드를 반복 호출한 시간과 Player FPS는 다른 지표입니다. 재구성 전 측정 수치는 새 소스의 성능 결과로 재사용하지 않습니다. 15일차에는 한 번에 한 조건만 바꾸고 화질·메모리·다운로드·발열의 변화를 구분합니다. 측정하지 않은 값은 미측정으로 기록합니다.
